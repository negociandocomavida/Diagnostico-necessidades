1. Termos de Uso

O que é este serviço

O Diagnóstico de Necessidade é uma ferramenta digital desenvolvida por Renan Cassimiro, disponível em negociandocomavida.com.br. A ferramenta utiliza inteligência artificial para identificar necessidades humanas não atendidas com base na teoria de Abraham Maslow, oferecendo caminhos de reflexão e possíveis soluções para conflitos pessoais e profissionais.

Importante: Esta ferramenta tem caráter educativo e reflexivo. Não substitui atendimento psicológico, terapêutico ou médico. Se você estiver passando por uma crise emocional grave, busque ajuda profissional.

Acesso e pagamento

O acesso ao diagnóstico é pago. Ao adquirir um pacote, você recebe uma quantidade específica de créditos que podem ser usados para realizar diagnósticos. Os créditos não têm prazo de validade e não são reembolsáveis após o uso.

  • 1 diagnóstico — R$ 5,00
  • 5 diagnósticos — R$ 20,00
  • 15 diagnósticos — R$ 45,00

Uso adequado

Ao usar esta ferramenta, você concorda em:

  • Usar o serviço apenas para fins pessoais e legítimos
  • Não tentar contornar o sistema de créditos ou acesso pago
  • Não compartilhar sua conta com terceiros
  • Não usar a ferramenta para fins que prejudiquem terceiros

Limitação de responsabilidade

O Negociando com a Vida não se responsabiliza por decisões tomadas com base nos diagnósticos gerados. A ferramenta oferece reflexões e sugestões baseadas nas informações fornecidas pelo usuário, mas o contexto completo de cada situação é de conhecimento exclusivo do próprio usuário.

Modificações

Podemos atualizar estes termos a qualquer momento. Mudanças significativas serão comunicadas por e-mail ou aviso no site.

2. Política de Privacidade

Quais dados coletamos

Coletamos apenas os dados necessários para o funcionamento do serviço:

  • E-mail: para criar e identificar sua conta
  • Senha: armazenada de forma criptografada pelo Supabase
  • Relatos enviados: o texto que você digita para o diagnóstico é processado pela API da Anthropic para gerar a resposta
  • Dados de uso: quantidade de créditos utilizados

Como usamos seus dados

  • Para criar e gerenciar sua conta
  • Para processar o diagnóstico via inteligência artificial
  • Para controlar o uso de créditos
  • Para comunicações relacionadas ao serviço

Com quem compartilhamos

Seus dados são processados pelos seguintes parceiros tecnológicos:

  • Supabase: armazenamento seguro de conta e créditos
  • Anthropic: processamento do texto para geração do diagnóstico
  • Netlify: hospedagem do site
  • Kiwify: processamento de pagamentos

Não vendemos, alugamos ou compartilhamos seus dados com terceiros para fins comerciais.

Armazenamento e segurança

Seus dados são armazenados em servidores seguros localizados na América do Sul (São Paulo). A chave de API utilizada para processar os diagnósticos fica protegida no servidor e nunca é exposta ao navegador.

Cookies

Utilizamos apenas cookies essenciais para manter sua sessão ativa enquanto você usa o serviço. Não usamos cookies de rastreamento ou publicidade.

3. Seus direitos (LGPD)

De acordo com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Acesso: saber quais dados temos sobre você
  • Correção: corrigir dados incorretos
  • Exclusão: solicitar a exclusão da sua conta e dados
  • Portabilidade: receber seus dados em formato legível
  • Revogação: retirar seu consentimento a qualquer momento
